# Linux tools

Linux is the primary/reference implementation of this repository.

| Directory | Content | Status |
| --- | --- | --- |
| [`1_shell_bash_commands/`](1_shell_bash_commands/) | Short commands for diagnostics and administration | reference fragments, do not run the entire directory |
| [`2_services/`](2_services/) | IaC, containers, Kubernetes, observability, databases, and service configs | mixed current/historical; check READMEs and versions |
| [`3_scripts_bash_python/`](3_scripts_bash_python/) | Ready-to-use Bash/Python/Go utilities | maintained utilities + separately marked legacy examples |
| [`fedora/`](fedora/) | Fedora Workstation bootstrap | primary, maintained |
| [`ubuntu/`](ubuntu/) | Ubuntu bootstrap | 24.04 maintained, 22.04 archive |

Canonical theory on languages and DevOps/SRE is maintained in separate [knowledgebase repositories](../what_to_learn/). Existing legacy notes are temporarily preserved in this repo and can only be deleted after a verified migration.
