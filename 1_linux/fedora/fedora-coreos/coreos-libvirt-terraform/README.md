# Historical Terraform example

Этот каталог сохранён как personal reference и не входит в maintained bootstrap.
Он использует старую схему libvirt/Ignition providers и hardcoded paths; не
применять без миграции provider versions, variables и state.

Для текущего локального запуска используй соседний
`../pure_install_on_libvirt.sh`, который принимает image и Ignition config
явными аргументами. Актуальную учебную lab следует вести в
[`5_devops_sre_knowledgebase`](https://github.com/krasnosvar/5_devops_sre_knowledgebase).
