# Эффективная работа с AI-агентами

Русскоязычная база по настройке и использованию AI-агентов для
разработки: инструкции, конфиги, субагенты, skills, hooks, MCP,
Desktop-приложения, источники и китайская экосистема. Используется в
разных проектах и командах. Дата проверки: 2026-11-19.

Главные принципы: конкретная цель и критерий готовности; один агент
для простой задачи; делегирование самостоятельных частей; проверка
результата; учёт расхода всей команды.

## Быстрый старт

1. Выберите приём в [1_setup](1_setup/README.md) и клиент в
   [2_tools](2_tools/).
2. Прочитайте, [как ставить задачу агенту](3_prompting/README.md).
3. Проверьте, что говорят исследования: [4_studies](4_studies/README.md).

## Состояние проверки

Подробно разобраны: Claude Code, Codex, Antigravity, Gemini CLI и общие
приёмы настройки. Обзорно по документации: Cursor, Copilot, Aider,
opencode, Cline, Windsurf (`2_tools/other`). Пометки «не проверено» в
файлах означают, что первоисточник не получен.

Примеры не устанавливаются автоматически. Перед применением проверьте
версию клиента, доступные модели и политики организации.
[MAINTENANCE.md](MAINTENANCE.md) описывает обновление и проверку.
