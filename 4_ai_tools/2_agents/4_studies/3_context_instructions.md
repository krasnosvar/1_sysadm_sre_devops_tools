# Контекст и инструкции

## 1. Evaluating AGENTS.md

Gloaguen, Mündler-Sasahara, Müller, Raychev, Vechev, 2026-02-12, v3
2026-09-29. https://arxiv.org/abs/2602.11988

- Эксперимент: SWE-bench Lite (300 задач) и CTXbench (138 задач, 12
  репозиториев с файлами контекста). Агенты: Claude Code (Sonnet 4.5),
  Codex (GPT-5.2, GPT-5.1 mini), Qwen Code.
- Результат: файлы, созданные LLM, дали около -0,5% (SWE-bench) и -2%
  (CTXbench), незначимо. Файлы, написанные разработчиками: +2,4%,
  незначимо, но лучше созданных LLM на 7% (p=0,038). Стоимость выросла
  на 20% и 23% (файлы LLM) и до 19% (файлы разработчиков). Обзоры
  репозитория не помогли.
- Ограничения: только Python, одна выборка на агента, небольшой
  CTXbench, измерено только решение задачи.
- Вывод: держите в AGENTS.md только нестандартные правила, а не обзор
  репозитория.

Из полного текста (через пересказ, таблицы не читались):

- SWE-bench Lite: 300 задач из 11 репозиториев; CTXbench: 138 задач из 12
  нишевых Python-репозиториев с файлами контекста, написанными
  разработчиками. Qwen Code работал на Qwen3-30B-coder.
- Файлы LLM: -0,5% (p=0,87) и -2% (p=0,37), оба незначимы. Файлы
  разработчиков: +2,4% (p=0,21 к варианту без файла).
- Агенты выполняют до 3,92 лишних шага; упомянутые в файле инструменты
  используют чаще, но обзор репозитория не ускоряет поиск нужных
  файлов. Если удалить остальную документацию, файлы LLM дают около
  +2,7%.

## 2. Context Rot

Hong, Troynikov, Huber (Chroma), 2025-07-14.
https://www.trychroma.com/research/context-rot

- Эксперимент: 18 LLM (Claude, GPT, Gemini, Qwen3), поиск иголки с
  отвлекающими фрагментами, LongMemEval (около 113 тысяч токенов против
  около 300), повтор слов (25-10000).
- Результат: точность падает с ростом длины во всех экспериментах.
  Даже один отвлекающий фрагмент снижает точность. На LongMemEval
  короткий сфокусированный контекст значимо лучше полного у всех
  семейств моделей.
- Ограничения: простые синтетические задачи, механизм не проверен,
  отвлекающие фрагменты подбирались вручную, к кодингу напрямую не
  относится.
- Вывод: давайте агенту минимально нужный контекст.

## 3. MCPVerse

Lei, Yang, Sun, Lin, 2025-08-22, v2 2025-10-11.
https://arxiv.org/abs/2508.16260 (только аннотация)

- Эксперимент: более 550 реальных инструментов, пространство действий
  более 140 тысяч токенов, режимы Oracle, Standard и Max-Scale.
- Результат: большинство моделей ухудшаются при больших наборах
  инструментов; Claude-4-Sonnet получает выигрыш. Цифр по числу
  инструментов на странице нет.
- Ограничения: не бенчмарк кодинга, детали не читались.
- Вывод: ограничивайте набор MCP-инструментов нужным для задачи.
