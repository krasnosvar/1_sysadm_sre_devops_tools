# Исследования: уже проведённые эксперименты

Статьи и отчёты о реальных экспериментах с AI-агентами для кодинга:
что сравнивали, на чём, что получилось, какие ограничения. Охват с
2025-01, акцент на последние два месяца (с 2026-09-19). Числа взяты со
страниц работ. Большинство свежих работ прочитаны по аннотации; это
указано у каждой. Многие из них препринты без рецензии.
