# Качество, сопровождаемость и безопасность кода агентов

Все пункты прочитаны по аннотации. Большинство работ наблюдательные
(по данным репозиториев), а не контролируемые эксперименты, поэтому
причинность не доказана.

## Coding Agents Propagate Vulnerabilities in Code Bases

Sun, Mündler-Sasahara, Vero, Vechev, 2026-11-08.
https://arxiv.org/abs/2611.11455

- Эксперимент: агенты пишут новый код рядом с уязвимым или безопасным
  кодом. 96 backend-задач, 20 пар задач на C/C++ (безопасность памяти).
  Модели в аннотации не названы.
- Результат: небезопасный контекст снижает долю корректных и безопасных
  решений в среднем на 3,4%; в C/C++ разрыв 35,4%. Указание «следуй
  стилю» усиливает перенос, «будь осторожен с безопасностью» ослабляет,
  но не убирает. Агенты объясняют выбор копированием в 76,5% случаев, а
  уязвимость осознают в 69,9%.
- Вывод: агенты берут существующие уязвимости как шаблон.

Из полного текста (через пересказ; идентификатор статьи и названия
моделей стоит сверить на arxiv.org/abs/2611.11455):

- Агенты: Claude Code (Opus 5, Opus 5.5), Codex (GPT-5.6, GPT-6) и GLM
  5.3. Метрика pass^sec: решение корректно и без уязвимости.
- Backend: 96 задач (24 сценария на 4 фреймворка), 3 генерации. Рядом с
  небезопасным кодом среднее падение 3,4% (GLM -4,5%, Opus 5 -2,1%);
  рядом с безопасным среднее рост 4,4%.
- C/C++: 20 пар из 5 проектов, 5 генераций; разрыв 25-49% (среднее
  35,4%); у одной модели 91% против 42%. Предупреждают пользователя в
  0-11,8% случаев.
- Ограничения: тесты дают нижнюю границу, синтетические соседи, малая
  выборка C/C++ (только безопасность памяти и патчи одной функции),
  возможное попадание кода в обучение.

## Reliable Mining of Heterogeneous AI Coding-Agent Data

Yu, Liu, Zhang, 2026-11-15. https://arxiv.org/abs/2611.20297

- Эксперимент: 71 677 pull request шести агентов.
- Результат: PR с трейлером соавтора: слиты 55,6% против 77,5%. Без
  доминирующего агента разрыв -21,8 п.п. превращается в +23,7 п.п.
  (парадокс Симпсона). AUC прогноза слияния 0,774, с контекстом 0,832; в
  момент создания PR 0,741, при проверке во времени 0,641.
- Ограничения: ретроспективно, не причинно.
- Вывод: агрегированная статистика PR разных агентов может давать
  обратные выводы.

## Do AI Coding Agents Write Infrastructure as Code Like Humans?

Barrak, Ksontini, Wehbe, 2026-10-25. https://arxiv.org/abs/2610.34613

- Эксперимент: 349 156 IaC pull request из 49 241 репозитория; люди,
  боты, скрытые и заявленные агенты; 2645 сопоставленных пар Terraform.
- Результат: следы агентов в 12,3% PR. PR агентов примерно в 4 раза
  больше. Скрытые агенты: слияние 87,4% против 78,9% у людей в целом, но
  внутри тех же репозиториев на 4,0 п.п. реже. Заявленные агенты: на
  8,4 п.п. реже при том же типе изменения. Запахи кода: 10,4% против
  10,3% (OR 1,02, CI 0,83-1,25).
- Ограничения: «скрытых» агентов определяют по следам.
- Вывод: агенты правят инфраструктуру больше, по запахам кода не хуже
  людей.

## CodeHealth Predicts the Token Cost of Agentic Code Review

Heander, Borg, Söderberg, Rydenfält, 2026-10-15.
https://arxiv.org/abs/2610.21914

- Эксперимент: предварительно зарегистрированное исследование, 465 PR
  агентов из 246 репозиториев (AIDev), конвейер из 5 агентов, 3 LLM.
- Результат: каждый пункт CodeHealth связан с токен-стоимостью ревью и
  правок на 3,5-6,1% ниже. Размер PR эффект не объясняет; поправка на
  размер файлов поглощает связь.
- Ограничения: наблюдательное, эффект скромный.
- Вывод: агенту дороже ревьюить и чинить код с плохим здоровьем.

## Who Finishes the Job?

Takerngsaksiri, Duong, Barnett, 2026-09-22.
https://arxiv.org/abs/2609.26847

- Эксперимент: 6774 влитых PR пяти агентов (Codex, Copilot, Devin,
  Cursor, Claude Code) против 5044 PR людей из тех же репозиториев (от
  500 звёзд).
- Результат: шансы последующих исправлений у агентов в 1,62 раза выше;
  69,6% исправлений делает тот же агент; 76,4% исправляющих PR написаны
  агентами. Каппа LLM-судьи 0,78, точность 90%.
- Ограничения: популярные репозитории, 5 агентов, ошибки судьи.
- Вывод: агенты чаще требуют доработки, и в основном дорабатывают себя.

## Not All Agents Are Equal

Kraishan, 2026-09-12. https://arxiv.org/abs/2609.17598

- Эксперимент: 37 623 PR пяти агентов, сопоставление с людьми, 2807
  репозиториев, период с 2024-12 по 2025-07.
- Результат: откаты Codex 6,1% против 11,5% у людей (OR 0,50), Devin
  14,5% (OR 1,31). Запахи безопасности у агентов реже (OR 0,63). Первое
  ревью Claude Code ждёт медиану 12,6 часа.
- Вывод: качество зависит от вендора, а не от «агент против человека».

## AI IDEs or Autonomous Agents?

Agarwal, He, Vasilescu, 2026-01-20. https://arxiv.org/abs/2601.13597

- Эксперимент: разность разностей с шахматным внедрением,
  сопоставление репозиториев, данные AIDev, первый PR агента как момент
  внедрения.
- Результат: сильный рост скорости только если агент первый ИИ-инструмент
  проекта; предупреждения статического анализа +18%, когнитивная
  сложность +39%.
- Вывод: скоростной выигрыш затухает, а технический долг остаётся.

## Will It Survive?

Rahman, Begoug, Shihab, 2026-01-23 (v3 2026-11-14).
https://arxiv.org/abs/2601.16809

- Эксперимент: 648 959 строк, 2794 PR, 215 репозиториев, Copilot, Codex,
  Devin.
- Результат: код агентов меняется позже (HR 0,83, CI 0,75-0,93) при
  равных весах PR; без весов значимости нет; Devin в целом HR 0,95.
- Ограничения: на рецензии; результат зависит от агента, даты и
  взвешивания.
- Вывод: код агентов не одноразовый, долговечность зависит от условий.
