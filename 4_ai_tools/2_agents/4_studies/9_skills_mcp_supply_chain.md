# Skills, MCP, правила: польза и риски цепочки поставок

Все пункты прочитаны по аннотации, если не указано иное.

## An Empirical Study of Agent Skills' Downstream Utility

Cheng, Zhao, Liu, Huang, Xing, Ren, 2026-10-06 (v2 2026-10-08).
https://arxiv.org/abs/2610.08875

- Эксперимент: 87 задач SkillsBench, польза skill это разница pass rate
  с вариантом без skill при той же паре модель и harness; 9
  конфигураций, корпус 37 596 skills. Модели в аннотации не названы.
- Результат: одни и те же skills помогают в одних конфигурациях и
  вредят в других на 36,78% задач. Перерейтинг кандидатов по
  поддержке нужных операций даёт +4,35-5,80 п.п. pass rate первого
  выбора. Stage Plan и Dependency DAG лучше простого порядка
  использования. Выведено 17 практик написания.
- Ограничения: 87 задач, разбор через LLM с проверкой авторов.
- Вывод: польза skill зависит от модели и harness, её нужно мерить.

## Scanning the Harness: Configuration Exposures in AI Coding-Agent Supply Chains

Kapner, Soceanu, Petrunin, Gartner, v1 2026-09-07 (v3 2026-09-25).
https://arxiv.org/abs/2609.07360

- Эксперимент: 3171 публичный репозиторий GitHub (2660 настроек
  агентов, 511 коллекций skills), 6 категорий рисков.
- Результат: непинованные MCP-пакеты в 9,8% настроек (24,5% среди
  имеющих MCP); широкие права исполнения 2,5%; широкое
  предварительное одобрение инструментов в skills 3,8%; объединение
  409 настроек (15,4%).
- Ограничения: нет рантайм-последствий и оценки полноты сканера.
- Вывод: заметная доля публичных конфигураций агентов небезопасна.

Из полного текста (через пересказ):

- Сканер из 31 правила (6 в основных результатах); ручная проверка
  одним автором, 752 вердикта (согласие 93,3%). Находки: непинованные
  MCP-пакеты 260 (9,8%), широкая преодобренность инструментов в skills
  101, широкие права исполнения 67, skills без frontmatter 60. Примеры:
  `npx -y @scope/server`, `Bash(python:*)`.
- Ограничения: учтены декларации, а не эксплойты; полнота сканера не
  измерена; один рецензент; нет доверительных интервалов.

## "Do Not Mention This to the User": Malicious Agent Skills in the Wild

Liu, Chen, Zhang, Deng, Li, Ning, Zhang, 2026-02-06 (v4 2026-06-10),
USENIX Security 2026. https://arxiv.org/abs/2602.06547

- Эксперимент: 98 380 skills из двух реестров, статический и
  динамический анализ.
- Результат: 157 вредоносных skills, 632 уязвимости, 13 техник, в
  среднем 4,03 на skill; больше половины от одного актора; после
  раскрытия удалены все 157.
- Вывод: реестры skills уже содержат вредоносные расширения.

## Package Hallucination Attacks on Coding Agents (PackHallu)

Wang, Jiang, Wang, Gong, 2026-10-07. https://arxiv.org/abs/2610.09264

- Эксперимент: эволюционная оптимизация инъекций в rule-файлы
  (AGENTS.md, .cursorrules), чтобы агент устанавливал несуществующие
  пакеты; много бенчмарков, моделей и фреймворков.
- Результат: в аннотации заявлен высокий процент успеха и перенос между
  моделями, чисел нет.
- Вывод: rule-файлы из сообщества это вектор атаки на цепочку поставок.

## IssueTrojanBench

Singh, Yang, Chen, 2026-07-22. https://arxiv.org/abs/2607.20759

- Эксперимент: вредоносные issue, 4 категории атак, 6 каналов
  доставки; Cursor, Claude Code, Codex Desktop; GPT-5.3 Codex, GPT-5.4,
  Sonnet 4.6.
- Результат: 66,5% вредоносных issue проходят все защиты; отказы почти
  полностью даёт модель, а не агентный слой; Sonnet 4.6 избирательнее
  блокирует опасные действия.
- Вывод: защита уровня агента мало добавляет к защите модели.
