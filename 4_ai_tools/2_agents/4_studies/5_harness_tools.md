# Harness и инструменты

## SWE-agent: интерфейс агента с компьютером

Yang, Jimenez, Wettig, Lieret, Yao, Narasimhan, Press, 2024-05-06, v3
2024-11-11. https://arxiv.org/abs/2405.15793

- Эксперимент: абляции интерфейса на SWE-bench Lite (300 задач) с GPT-4
  Turbo; основные модели GPT-4 Turbo и Claude 3 Opus.
- Результат: полная конфигурация решает 18,0%. Без проверки линтером при
  редактировании 15,0%, без команды редактирования 10,3%. Итеративный
  поиск вместо суммарного 12,0%, без поиска 15,7%. Окно просмотра файла:
  30 строк даёт 14,3%, весь файл 12,7%, 100 строк 18,0%. Полная история
  вместо последних 5 наблюдений 15,0%. Claude 3 Opus решает 13,0%.
- Ограничения: интерфейс подбирался вручную на малом числе примеров под
  GPT-4 Turbo, лимит $4 на задачу, модели устарели. Раздел Limitations
  не читался.
- Вывод: при той же модели дизайн инструментов даёт разницу до 8 п.п. и
  больше.
