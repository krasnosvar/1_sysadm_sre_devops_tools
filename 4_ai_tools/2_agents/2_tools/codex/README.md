```bash

```

Запускайте клиент из нужного проекта и передайте задание
(см. [как ставить задачу](../../3_prompting/README.md)). Простую задачу
выполняйте без субагента. Пример роли сначала установите по руководству: имя
файла в этой базе само по себе не регистрирует агента в Codex.
