## Как читать

Каждый файл устроен одинаково: что это, где живёт, минимальный
пример, риски, как проверить. Примеры не устанавливаются автоматически.
Перед применением сохраните исходный файл настроек, проверьте версию
клиента и политики организации. Ключи и токены только плейсхолдерами.

Клиенты и Desktop: [2_tools](../2_tools/). Рабочие сценарии:
[3_prompting](../3_prompting/README.md).
