# Инструкции: AGENTS.md, CLAUDE.md, GEMINI.md

## Что это

Файл правил, который клиент добавляет в контекст модели. Это
контекст, а не запрет: модель может ошибиться. Жёсткие правила
делайте через [hooks](5_hooks.md) или [права](2_configs_permissions.md).

## Где лежат

| Клиент | Файлы |
| --- | --- |
| Claude Code | `./CLAUDE.md` или `./.claude/CLAUDE.md`, `~/.claude/CLAUDE.md`, `CLAUDE.local.md` (личный, в `.gitignore`), `.claude/rules/*.md` |
| Codex | `~/.codex/AGENTS.md` (или `AGENTS.override.md`), `AGENTS.md` от корня проекта вниз |
| Gemini CLI | `~/.gemini/GEMINI.md`, `GEMINI.md` в проекте и родителях |

Источники: https://code.claude.com/docs/en/memory,
https://learn.chatgpt.com/docs/agent-configuration/agents-md,
https://geminicli.com/docs/cli/gemini-md/

## Как работает

- Claude Code: файлы от корня до рабочего каталога конкатенируются, а
  не переопределяют друг друга. Файлы в подкаталогах грузятся по
  требованию.
- Размер: целиться меньше 200 строк на файл. Файл больше 4 MiB
  пропускается целиком.
- Импорт: `@path/to/file`. Импорт раскрывается вместе с файлом и не
  уменьшает стоимость контекста.
- `.claude/rules/*.md` с `paths:` (glob) грузятся только при работе с
  подходящими файлами.
- Codex: один файл на каталог, лимит `project_doc_max_bytes`, по
  умолчанию 32 KiB.

## Один файл для нескольких клиентов

Claude Code (v2.1.277 и новее) читает `AGENTS.md` напрямую, только
если рядом нет `CLAUDE.md`. Общий файл: хранить правила в
`AGENTS.md`, а в `CLAUDE.md` написать одну строку:

```text
@AGENTS.md
```

Символьная ссылка на Windows ненадёжна. Для Gemini CLI имя файла
меняется настройкой `context.fileName`.

## Минимальный пример

```text
# Правила проекта
- Язык ответов: русский. Строки не длиннее 80 символов.
- Перед изменением кода запустить тесты: make test.
- Не менять каталог migrations/ без явной просьбы.
- Секреты не читать и не выводить (.env, ключи).
```

## Что писать и чего не писать

Писать: команды сборки и проверки, границы владения файлами,
соглашения, которые нельзя вывести из кода. Не писать: пересказ
кода, длинные справочники, секреты, устаревшие заметки. Коротко и
конкретно лучше длинно и общо. Длинный справочник вынесите в файл
с `@`-импортом или в skill.

## Как проверить

В Claude Code команда `/status` показывает загруженные источники, а
`claude doctor` ошибки. Задайте новой сессии вопрос по правилу и
проверьте ответ. После правки начните новую сессию.
