# Плагины и слеш-команды

Источники: https://code.claude.com/docs/en/plugins,
https://code.claude.com/docs/en/commands

## Плагины

Плагин это каталог с манифестом `.claude-plugin/plugin.json`.
Внутри могут быть skills, агенты, hooks (`hooks/hooks.json`),
`.mcp.json`. Он упаковывает механизмы, но не делает их безопаснее:
плагин исполняет код с вашими правами.

- Маркетплейс: каталог с `.claude-plugin/marketplace.json`.
  Установка по имени вида `name@marketplace`, интерфейс `/plugin`.
- Область установки: user, project (через `.claude/settings.json`),
  local.
- Включённый плагин добавляет имена и описания своих skills в
  контекст на каждом ходу: лишние плагины стоят токенов.
- Облачные сессии локальные плагины не загружают.

Перед установкой: источник, содержимое hooks и MCP, лицензия, дата
последнего коммита, способ отключения.

## Слеш-команды

Команда распознаётся только в начале сообщения. Свои команды в
Claude Code создаются как skills (см. [4_skills.md](4_skills.md)).
Слияние каталога `.claude/commands` со skills не проверено. В одном
сообщении можно связать до 6 skills.

Полезные встроенные команды: `/status` (источники инструкций),
`/context` (расход контекста), `/compact`, `/clear`, `/mcp`,
`/plugin`, `/cost`, `/usage`. Точный список зависит от версии.
