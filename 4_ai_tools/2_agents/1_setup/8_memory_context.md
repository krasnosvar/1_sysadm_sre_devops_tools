# Память, контекст и длинные задачи

Источники: https://code.claude.com/docs/en/context-window,
https://code.claude.com/docs/en/memory,
https://code.claude.com/docs/en/common-workflows

## Контекст

Всё, что видит модель, занимает окно и пересылается на каждом ходу.
Большое окно не значит, что полезна каждая строка. Сначала поиск,
затем нужные диапазоны. Статья Anthropic с разбором:
[context-and-evals](../4_studies/reviews/context-and-evals.md).

## Команды Claude Code

`/context` показывает расход, `/compact <фокус>` сжимает историю,
`/clear` между несвязанными задачами. Автокомпакция срабатывает у
лимита. Окно 1M токенов доступно только части моделей.

Переживают компакцию: корневой CLAUDE.md и правила без `paths`,
auto memory, описания skills, план plan mode. Не переживают:
правила с `paths` и вложенные CLAUDE.md (подгружаются заново),
контекст, добавленный хуками. После компакции перечитываются до 5
недавних файлов; файл больше 5000 токенов возвращается ссылкой.

## Auto memory

Каталог `~/.claude/projects/<project>/memory/`; в контекст грузятся
первые 200 строк или 25 КБ файла `MEMORY.md`. Отключение:
`CLAUDE_CODE_DISABLE_AUTO_MEMORY=1`. Не сохраняйте секреты и
личные данные.

## Worktree

`claude --worktree <name>` создаёт изолированную сессию в отдельном
git worktree (нужен хотя бы один коммит). В субагенте:
`isolation: worktree`. Подробности очистки: официальная страница
worktrees (не читалась, не проверено). Не создавайте worktree там,
где это запрещает правило проекта.

## Длинные задачи

Сохраняйте handoff: цель, сделанное, решения, следующий шаг, проверки.
Состав handoff: [как ставить задачу](../3_prompting/README.md).
Перед продолжением читайте существующий handoff и уточняйте только
изменчивые факты. Разбор статей о длинных задачах:
[context-and-evals](../4_studies/reviews/context-and-evals.md).
