# Что куда класть

| Нужно | Механизм | Почему |
| --- | --- | --- |
| Устойчивое правило проекта | Инструкция ([1](1_instructions.md)) | Короткий контекст на каждый ход |
| Повторяемый процесс, нужный иногда | Skill ([4](4_skills.md)) | Грузится по требованию |
| Жёсткий запрет или автоматика | Hook ([5](5_hooks.md)) | Выполняется вне рассуждения модели |
| Права и границы файловой системы | Permissions, sandbox ([2](2_configs_permissions.md)) | Принуждение клиентом и ОС |
| Доступ к внешней системе | MCP ([6](6_mcp.md)) | Структурные инструменты |
| Тяжёлое чтение и диагностика | Субагент ([3](3_subagents_roles.md)) | Изолированный контекст |
| Набор для команды | Плагин ([7](7_plugins_commands.md)) | Упаковка и распространение |
| Состояние между сессиями | Память, handoff ([8](8_memory_context.md)) | Не терять решения |

Правила выбора:

1. Если нарушение недопустимо, не полагайтесь на текст инструкции:
   нужен hook или право.
2. Если процесс нужен не каждый ход, это skill, а не строка в
   постоянной инструкции.
3. Не устанавливайте расширение ради наличия: определите задачу,
   права, источник, проверку и способ отключения.
4. Одно изменение за раз, затем проверка на малой задаче.
