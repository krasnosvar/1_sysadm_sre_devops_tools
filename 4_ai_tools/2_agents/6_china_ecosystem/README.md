# Китайская экосистема ИИ для кодинга и агентов

Раздел отвечает на вопрос: какие китайские модели и клиенты стоит учитывать, как
подключить их к привычным агентам и какие риски проверить.

Факты здесь устаревают быстрее остальной базы (новые версии выходят
раз в несколько недель). У каждой записи есть источник. Пометка
«не проверено» означает, что первоисточник не открыт. Версии, цены и
лицензии перед использованием сверяйте с первоисточником.

## Принципы

- Выбирать по своей задаче и приёмке, а не по рейтингу. См.
- Результаты бенчмарков на странице модели это данные авторов, а не
  независимое измерение.
- Для рабочего кода сначала проверить политику данных организации
  ([риски](5_risks.md)).
- Локальные раннеры и серверы описаны в
  [1_local_tools.md](../../1_tools_catalog/1_local_tools.md) и
  [2_server_tools.md](../../1_tools_catalog/2_server_tools.md).
