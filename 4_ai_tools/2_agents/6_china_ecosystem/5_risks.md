# Риски и проверки перед использованием

Решение принимает владелец данных и политики организации.

## Данные

- DeepSeek: по политике конфиденциальности (редакция 2026-02-10)
  данные хранятся в КНР, могут использоваться для обучения, отказ
  оформляется письмом по адресу из самой политики. Хранение действует,
  пока существует аккаунт.
  https://cdn.deepseek.com/policies/en-US/deepseek-privacy-policy.html
- Trae: см. [клиенты](2_clients.md). Утверждения о сроке хранения
  не проверены.
- Политики Moonshot, Z.ai, Alibaba, MiniMax: не проверено.
  Прочитайте до отправки кода.

## Лицензии весов

Лицензии Kimi K3 и K3.1 Pro, GLM-5.3, Qwen3.8 и MiniMax-M3 кастомные.
Условия коммерческого использования в этой базе не разобраны. У
MiniMax вторичный источник сообщает о смене лицензии (см.
[модели](1_models.md)). Читайте LICENSE в репозитории модели.

## Чеклист перед применением

- Разрешает ли политика организации отправку кода этому вендору.
- Где хранятся данные и можно ли отключить обучение на них.
- Не попадут ли секреты в контекст: убрать `.env`, ключи,
  внутренние адреса.
- Лицензия весов и условия API для коммерческого использования.
- Для самохостинга: источник весов, проверка хеша, изоляция
  процесса, отсутствие исходящих соединений без необходимости.
- Плагины и расширения клиента: источник, права, возможность
  отключения (как для любого стороннего кода).
- Версии моделей меняются: фиксируйте версию и пересматривайте
  выбор при обновлении.

## Для публичного и личного кода

Открытый код с минимальным риском проще пробовать на любых моделях.
Для рабочих и закрытых репозиториев сначала получите согласование,
затем проверяйте на синтетических задачах.
