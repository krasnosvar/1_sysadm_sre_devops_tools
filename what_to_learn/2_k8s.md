## Certifications

### CKA (Certified Kubernetes Administrator) — recommended

- [Linux Foundation CKA](https://training.linuxfoundation.org/certification/certified-kubernetes-administrator-cka/) — $395
- Format: **practical** terminal exam (2 hours, real cluster)
- Preparation: Killercoda CKA scenarios + [killer.sh](https://killer.sh) simulator
- Useful aliases during the exam: `alias k=kubectl`, `export do="--dry-run=client -o yaml"`

### CKAD (Certified Kubernetes Application Developer)

- [Linux Foundation CKAD](https://training.linuxfoundation.org/certification/certified-kubernetes-application-developer-ckad/) — $395
- Focus on application deployment: workloads, services, config, observability

### CKS (Certified Kubernetes Security Specialist)

- [Linux Foundation CKS](https://training.linuxfoundation.org/certification/certified-kubernetes-security-specialist/) — requires CKA
- [Killercoda CKS](https://killercoda.com/killer-shell-cks) — free labs
- [KodeKloud CKS](https://learn.kodekloud.com/user/courses/certified-kubernetes-security-specialist-cks) — course with labs
