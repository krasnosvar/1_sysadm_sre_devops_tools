## AWS

### Learning

- [roadmap.sh/aws](https://roadmap.sh/aws) — interactive AWS map
- [AWS Skill Builder](https://skillbuilder.aws/) — free official courses from AWS
- [AWS Free Tier](https://aws.amazon.com/free/) — 12 months of free resources for practice

### AWS Certifications

- **AWS Cloud Practitioner** — $100, entry level, good for getting started with AWS
- **AWS Solutions Architect Associate** — $300, most popular, highly recommended
- **AWS DevOps Engineer Professional** — $300, CI/CD + IaC + operations, for experienced professionals

Best course for SAA: [Adrian Cantrill](https://learn.cantrill.io/) (paid, high quality)
or Stephane Maarek on Udemy.

## Terraform / OpenTofu

- [developer.hashicorp.com/terraform/tutorials](https://developer.hashicorp.com/terraform/tutorials) — free official tutorials
- [terraform-best-practices.com](https://www.terraform-best-practices.com/) — best practices
- [registry.terraform.io](https://registry.terraform.io/) — public registry of modules and providers
- **Terraform Associate** — $70, online test, good start for IaC
- **OpenTofu** (fork, MIT license) — [opentofu.org](https://opentofu.org/)

## GCP

- [cloud.google.com/training](https://cloud.google.com/training) — free Google courses
- Unique strengths: BigQuery, Vertex AI, GKE Autopilot

## Azure

- [learn.microsoft.com](https://learn.microsoft.com/azure/) — free Microsoft training
- Strengths: Active Directory, .NET ecosystem, AKS
