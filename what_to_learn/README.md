# Where to find learning materials

This directory preserves older notes, roadmaps, and exercises as a legacy snapshot. Canonical and actively developed versions are located in separate repositories; new educational material is not duplicated here. Old files are deleted only after verifying that their content has been migrated to the owning knowledgebase.

| What to study | Canonical repository |
| --- | --- |
| Linux, containers, Kubernetes, IaC, CI/CD, observability, SRE, security, MLOps | [`5_devops_sre_knowledgebase`](https://github.com/krasnosvar/5_devops_sre_knowledgebase) |
| Go, standard library, concurrency, backend, system design | [`3_go_my_knowledgebase`](https://github.com/krasnosvar/3_go_my_knowledgebase) |
| Python, tooling, asyncio, backend, data/messaging, system design | [`4_python_my_knowledgebase`](https://github.com/krasnosvar/4_python_my_knowledgebase) |

Practical commands remain in [`../1_linux/`](../1_linux/), and ready-to-use operational utilities in [`../1_linux/3_scripts_bash_python/`](../1_linux/3_scripts_bash_python/).

Modification rule: theory and lab assignments are fixed in the owning knowledgebase. In this repository, we only update links or commands/utilities related to real operations; a legacy snapshot is not considered a source of truth.
